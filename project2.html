Portfolio Website

Project beschrijving

Voor dit project maakte ik een volledige portfolio website waarin ik mijn werk presenteer. De website is volledig responsief opgebouwd met Bootstrap en bevat HTML5 layout-elementen zoals header, nav, main, section, article, aside en footer.

🔧 Gebruikte technologieën

  • HTML5 - Semantische layout elementen
  • CSS3 - Custom styling met variabelen, transitions en hover effecten
  • Bootstrap 5 - Grid systeem en componenten
  • Leaflet.js - Interactieve kaart
  • Netlify Forms - Werkend contactformulier

💡 Wat heb ik geleerd?

Ik heb geleerd hoe ik een website structureer en responsief maak met het Bootstrap grid systeem. Ook heb ik ervaring opgedaan met het implementeren van externe bibliotheken zoals Leaflet en het deployen via Netlify. Het was een uitdaging om alles netjes te organiseren in de juiste mappenstructuur.

✅ Resultaat: Een volledig werkende portfolio website die voldoet aan alle eisen uit de projectopdracht.
