Weer App (API)

Project beschrijving

Deze applicatie haalt weergegevens op via een externe API (OpenWeatherMap) en toont deze aan de gebruiker. Gebruikers kunnen een stad ingeven en krijgen direct de temperatuur, luchtvochtigheid, windkracht en een beschrijving van het weer te zien. De data wordt live opgehaald en weergegeven.

🔧 Gebruikte technologieën

  • JavaScript (ES6+) - Fetch API, async/await, JSON
  • OpenWeatherMap API - Externe weerservice
  • HTML5 - Formulieren en dynamische content
  • CSS3 - Responsieve cards en animaties

💡 Wat heb ik geleerd?

Ik heb geleerd hoe ik data van een API kan ophalen en verwerken met fetch en async/await. Ook begrijp ik nu hoe ik met API keys werk, fouten afhandel en data dynamisch in de DOM injecteer. Dit was een belangrijke stap naar het werken met externe services.

🌤️ Resultaat: Een functionele weerapp die real-time data toont voor elke stad ter wereld.
