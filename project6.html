Smart Classroom (IoT)

Project beschrijving

Voor dit schoolproject ontwikkelde ik een systeem dat temperatuur en luchtkwaliteit meet in een klaslokaal. Sensoren (temperatuur, CO2, luchtvochtigheid) zijn verbonden met een Arduino die data doorstuurt naar een webserver. De data wordt live weergegeven op een dashboard met grafieken.

🔧 Gebruikte technologieën

  • Arduino - Hardware en sensoren uitlezen
  • C++ - Code voor de Arduino
  • JavaScript - Data visualisatie en dashboard
  • WebSockets - Real-time communicatie
  • Chart.js - Grafieken en data visualisatie

💡 Wat heb ik geleerd?

Ik heb geleerd hoe hardware en software samenwerken. Het was uitdagend om de sensordata correct uit te lezen en real-time naar een dashboard te sturen. Dit project gaf me een goed begrip van full-stack IoT ontwikkeling, van sensor tot user interface.

🎓 Resultaat: Een werkend IoT prototype dat klaslokalen comfortabeler en energie-efficiënter maakt.
