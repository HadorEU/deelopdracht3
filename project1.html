Smart Home Dashboard

Project beschrijving

Dit project is een volledig functioneel dashboard voor een smart home systeem. Het toont live data van sensoren (temperatuur, luchtvochtigheid, energieverbruik) en stuurt acties naar aangesloten devices via een MQTT-broker. De uitdaging lag in het real-time updaten van de UI zonder pagina refresh, wat ik heb opgelost met WebSockets.

📍 Locatie van dit project

Dit project werd ontwikkeld en getest in mijn thuisomgeving te Antwerpen. Hieronder zie je een kaart met de locatie.

🔧 Gebruikte technologieën

  • HTML5 - Semantische layout met main, section, article, aside
  • CSS3 - Flexbox, Grid, responsive design (geen horizontale scroll)
  • JavaScript (ES6+) - Fetch API, async/await, event listeners
  • Chart.js - Voor dynamische grafieken van energieverbruik
  • Leaflet.js - Voor een kleine kaart met sensoren in huis

💡 Wat heb ik geleerd?

Dit project was een echte gamechanger. Ik heb geleerd hoe je real-time data visualiseert, hoe je een schaalbare map structuur opzet en vooral: hoe belangrijk performantie is bij het ophalen van data. Ook heb ik mijn vaardigheden in het debuggen van async code sterk verbeterd.

⚡ Resultaat: Een 8/10 score van de docent en positieve feedback van medestudenten.
